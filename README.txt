SMARTSERVE — STAGE 1 PROTOTYPE

Open index.html in a browser to preview.

Includes:
- Light dashboard with orange accents
- Owner dashboard overview
- Orders, menu, tables and QR preview
- Kitchen display
- Waiter station
- Customer QR menu preview
- Reports and super-admin overview

IMPORTANT:
This is a front-end prototype using illustrative sample data.
It does not yet include live authentication, database persistence,
tenant isolation, payment processing, real QR ordering or realtime sync.
Those are planned for the next integration stage.
